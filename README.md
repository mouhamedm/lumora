## ✨ Features & Highlights

- **Monumental Interactions & Animations**: Powered by GSAP and ScrollTrigger for smooth scroll-driven effects and interactive card reveals.
- **Inertial Smooth Scrolling**: Integrated with [Lenis](https://github.com/darkroomengineering/lenis) for a fluid, momentum-based scrolling experience.
- **Custom Cursor & Parallax**: Physics-based interactive cursor and dynamic pointer tracking.
- **Bilingual Support (i18n)**: Seamless language switching between French (`fr`) and English (`en`) via `react-i18next`.
- **Modern Design System**: Built with Tailwind CSS v4 design tokens, dark aesthetic, glassmorphism, and responsive layouts across all devices.
- **Performance Optimized**: Lazy-loaded components, optimized assets, and clean code-splitting.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+) and `npm` installed.

### Installation

Clone the repository and install dependencies:

```bash
git clone git@github.com:mouhamedm/mmddev-react.git
cd mmddev-react
npm install
```

### Available Scripts

- **`npm run dev`** : Starts the local Vite development server with HMR.
- **`npm run build`** : Type-checks with `tsc` and builds the production bundle into `dist/`.
- **`npm run preview`** : Previews the production build locally.
- **`npm run lint`** : Runs ESLint to check code quality.
